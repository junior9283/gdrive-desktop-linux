# Decisões da 0.2 (interface)

Decisões tomadas durante a execução do plano `docs/superpowers/plans/2026-10-25-v0.2-interface.md` e da revisão final, no formato *o que foi decidido — por quê — custo se estiver errado*. Copiadas do registro de execução, que não fica no repositório.

## Decisões

- **Preparação:** seguir para a 0.2 num branch novo (feat/v0.2-interface) criado a partir de feat/v0.1-motor, sem juntar ao main — o dono pediu "siga para as próximas versões" sem escolher entre juntar, enviar ou manter — custo se errado: juntar depois (git merge local).
- **Preparação:** executar o plano sem esperar a revisão dele — o pedido foi seguir; o plano fica no repositório para leitura — custo se errado: retrabalho nas tarefas que ele quiser mudar.
- **Pré-checagem (T2 (estado "error" usa summary.errors da 0.1) × T5 (errors() vira a fonte)):** na T2 o estado error usa a contagem atual; a T5 troca a fonte e ajusta o teste — custo: nenhum.
- **Tarefa 1:** no lugar de `error_name(&zbus::Error)`, o `ServiceError` foi para o gdl-ipc (o proxy devolve o erro já tipado) com `short_name()` — o proxy tipado já separa os erros; o nome curto serve à ponte da interface — custo: nenhum.
- **Tarefa 1:** simplify com 2 agentes (reuso+simplificação; eficiência+altitude) em vez de 4, nas tarefas pequenas — mesmo escopo de ângulos, metade do custo — custo: algum achado a menos.
- **Tarefa 2:** o script task-start procura 'Task N' e o plano usa 'Tarefa N'; leio a seção do plano direto (sed) e anoto BASE à mão — custo: nenhum. BASE T2=b6654ec
- **Tarefa 2:** a foto só vem de https://*.googleusercontent.com ou do mesmo servidor da API (o simulado) — o serviço baixaria qualquer URL que o about mandasse — custo se errado: foto vazia se o Google usar outro domínio.
- **Tarefa 3:** teste de progresso no nível D-Bus (upload_progress_reaches_activity) em vez do motor — o Harness já tem o envio empacado com StallConnectionAfterBytes — custo se errado: teste mais lento.
- **Tarefa 3:** andamento por SessionSlot::progress (método padrão) em vez de parâmetro &dyn Fn(u64) — reaproveita o objeto que já acompanha a sessão — custo se errado: renomear o trait.
- **Tarefa 3:** intervalo de 250 ms do sinal com watch no daemon em vez de EngineEvent::ActivityChanged — o canal de eventos é para avisos ao usuário — custo se errado: mover o encaminhamento.
- **Tarefa 4:** cópia em `Uploads cancelados` com o nome datado das cópias de conflito (`novo (local AAAA-MM-DD HHMMSS).txt`), não `novo.txt` como diz o Passo 1 — a semântica da própria tarefa pede "nome com data, nunca sobrescreve" — custo se errado: trocar o formato do nome.
- **Tarefa 4:** coluna `items.remote_size` (migração 3; a lista de erros da Tarefa 5 passa a ser a migração 4) — sem rede, o tamanho da versão da nuvem se perdia durante a edição local e o item voltaria com o tamanho errado — custo se errado: uma coluna a mais. Sem rede, a data de modificação fica a da edição até a próxima mudança da nuvem.
- **Tarefa 4:** ID desconhecido em CancelUpload responde `too-late`, não erro — a tela pode ainda mostrar o ID temporário de um envio que já terminou — custo se errado: um erro de digitação também vira too-late.
- **Tarefa 4:** só arquivos são canceláveis (pasta → too-late) — cancelar a criação de uma pasta com filhos exigiria decidir o destino deles — custo se errado: acrescentar o caso de pasta depois.
- **Tarefa 4:** Lost and Found generalizado em `kept.rs` (KeptCopies/KeptFolder/Kept) e no FUSE como Node::Kept/KeptFile — tirar uma cópia de qualquer uma das duas pastas vira arquivo novo no Drive — custo se errado: nenhum além do renome.
- **Tarefa 5:** migração 4 (a 3 ficou com remote_size na Tarefa 4), teste `migration_4_adds_error_columns_and_keeps_the_queue` — custo se errado: nenhum.
- **Tarefa 5:** só falhas não passageiras entram na lista (sem rede, limite de taxa e 5xx não) — o Drive original não acusa erro por queda momentânea — custo se errado: um erro antigo pode continuar na lista enquanto a falha atual é passageira.
- **Tarefa 5:** `DriveError::TooLarge` novo (403 maxFileSizeExceeded / 413) para a categoria too-large; os textos de cada categoria ficam para a interface (Tarefa 16), não no main.ftl do serviço — custo se errado: mover os textos.
- **Tarefa 5:** Status.errors = itens com erro na fila + cópias do Lost and Found (contagem barata em `summary`, mesma regra de `errors()`); com cópias no Lost and Found o estado fica `error` até o usuário tirá-las — custo se errado: separar o aviso do Lost and Found do estado.
- **Tarefa 5:** `Retry("")` (linha do Lost and Found) responde InvalidArgs.
- **Tarefa 6:** famílias opcionais como const OPTIONAL_KINDS (copied-as-shortcut, mount-moved, resume-syncing, offline) em vez de campo por aviso; NotificationSettings lista só as opcionais — o resto avisa algo que o usuário precisa saber — custo se errado: mover uma família para a lista.
- **Tarefa 6:** aviso "upload-canceled" (com ação open-canceled) vem do evento EngineEvent::UploadCanceled; SavedWhilePaused sai de finish_write só quando a gravação entra na fila (commit_write devolve se sobe) — custo se errado: um aviso a mais/a menos.
- **Tarefa 6:** o histórico também respeita replaces_key (falhas repetidas do mesmo arquivo, sem internet, pausa viram uma linha), como a área de trabalho — custo se errado: o sino mostra menos repetições do que o original.
- **Tarefa 6:** ServiceError::Managed criado já aqui (SetNotificationEnabled com política gerenciada), a Tarefa 8 reusa — custo se errado: nenhum.
- **Tarefa 7:** Store::pinned_children devolve Vec<Item> (pin None = "mixed") em vez de Vec<(Item, PinState)> — o par era redundante — custo se errado: nenhum fora do daemon.
- **Tarefa 7:** Engine::clear_cache/clear_offline viraram BlockCache::clear e PinManager::unpin_all (acessores já existentes) — custo: nenhum.
- **Tarefa 7:** DriveClient::search devolve só IDs (fields=id; metadados vêm do banco) e shared_with_me devolve SharedFile{file, owner, shared_ms} — custo se errado: um campo a mais na chamada.
- **Tarefa 7:** SearchResult.mime vazio para arquivos comuns (o banco não guarda o mime deles); pastas, Documentos Google e atalhos têm o tipo Google — custo se errado: a interface escolhe o ícone pela extensão.
- **Tarefa 7:** OpenItem file/folder usa xdg-open (ou o lançador de teste), nunca o DefaultWebBrowser; as ações open-lost-found/open-canceled também — custo se errado: pasta abriria no navegador da política.
- **Tarefa 7:** Drive simulado esconde "compartilhados comigo" da listagem e das mudanças (só sharedWithMe = true). FOCO PARA A REVISÃO FINAL: no Drive real, files.list "trashed = false" também traz itens compartilhados sem pai; o indexador grava parent None (invisíveis na montagem; a pesquisa já os ignora por parent IS NOT NULL).
- **Tarefa 8:** Restart reinicia no mesmo processo (laço em main.rs) em vez de sair com código 75 — não depende de o systemd religar; custo se errado: trocar por saída 75 e Restart=on-failure na unidade.
- **Tarefa 8:** binário da bandeja será gdrive-desktop-linux-tray (nome usado no .desktop de autostart) — custo se errado: renomear um arquivo.
- **Tarefa 8:** pending_cache_move é calculado no daemon (para o aviso) e de novo no Engine::open (para mover) — barato e mantém o motor independente; custo: uma leitura de arquivo a mais.
- **Tarefa 9:** proxy (DirectConnection/ProxyServer) é estado de processo em gdl_drive::set_network, aplicado pelo Daemon::new e lido em http_builder (vale também para o OAuth) — evita mexer na assinatura de DriveClient/AccessTokens/LoginFlow; custo se errado: passar Network explicitamente (vários Daemon no mesmo processo dividem o valor).
- **Tarefa 9:** teste de proxy roda o próprio binário de teste como subprocesso com HTTP(S)_PROXY — set_var é unsafe (edition 2024, unsafe_code=forbid); custo: um processo a mais no teste.
- **Tarefa 9:** o motivo da pausa fica no motor (PauseReasons: usuário e conexão limitada); a retomada do usuário também desfaz a da conexão limitada — custo se errado: o usuário retomaria e a sincronização seguiria em conexão limitada até a próxima mudança de rede (é o que ele pediu).
- **Tarefa 9:** download_respects_rx_limit conta os bytes que passaram pelo balde (Throttle::taken) em vez de medir tempo; o ritmo é provado em throttle_limits_rate com relógio pausado.
- **Tarefa 9:** ProxyServer inválido vindo de edição à mão continua caindo no proxy do sistema (com aviso no log, sem a URL), em vez de bloquear a rede — custo se errado: tráfego fora do proxy que o usuário escreveu errado no arquivo.
- **Tarefa 10:** TrayModel::from_status do plano virou TrayView::from_status (com service_down, icon_at e animated) — um struct só para nomes não acrescenta nada; custo se errado: um renome.
- **Tarefa 10:** ícones em estrutura de tema (assets/icons/hicolor/scalable/status/gdl-*.svg) em vez de assets/icons/tray/*.svg — IconThemePath do SNI espera um tema; o instalador (Tarefa 17) deve pôr a pasta em <prefixo>/share/gdrive-desktop-linux/icons; custo se errado: mover a pasta.
- **Tarefa 10:** "Conectado com N contas" aparece no lugar de "Tudo sincronizado" quando há mais de uma conta (a 0.2 sempre passa 0 ou 1) — gancho para multiconta.
- **Tarefa 10:** o lançador só inicia outra janela quando ninguém tem o nome (ServiceUnknown/NameHasNoOwner/UnknownObject); janela que não responde em 3 s só gera aviso — evita duas janelas durante a ativação pelo D-Bus.
- **Tarefa 10:** a bandeja lê DisableOnboardingDialog e DefaultWebBrowser dos arquivos de preferências (load_preferences), não pelo serviço — mesma fonte, sem ida ao D-Bus.
- **Tarefa 10:** assume_sni_available(true) no ksni — no login a bandeja pode subir antes do StatusNotifierWatcher do Plasma; custo: sem painel nenhum, fica rodando sem aparecer.
- **Tarefa 11:** Hotkey::register recebe também a conexão e a descrição (o plano tinha só gatilho e callback) — a conexão é o que permite testar sem o barramento do usuário; custo: nenhum.
- **Tarefa 11:** missing_portal_is_not_fatal usa um dbus-daemon privado (configuração sem ativação de serviços) em vez de ponto a ponto — o ashpd entra em pânico sem nome único (proxy.rs unique_name().unwrap()) e assume versão 1 quando o portal não responde; a conexão ponto a ponto virou um teste à parte (recusada antes de chamar o ashpd). Custo: o teste precisa do binário dbus-daemon (a CI precisa do pacote dbus-daemon).
- **Tarefa 11:** o prazo de 5 s vale só para o portal responder que existe; BindShortcuts fica sem prazo (o KDE pode pedir confirmação ao usuário). Na saída, a bandeja espera até 2 s para soltar o atalho.
- **Tarefa 12:** o brief cita gdl_ipc::error_name, que não existe — usei ServiceError::short_name e criei into_message (a CLI passou a usá-lo) — custo se errado: renomear.
- **Tarefa 12:** second_instance_forwards_open roda num dbus-daemon privado (PrivateBus), não ponto a ponto — dono de nome só existe num barramento; p2p_pair, PrivateBus e nobody_there foram para gdl-ipc (feature testing) e a bandeja os reaproveita — custo se errado: nenhum além do dbus-daemon no CI.
- **Tarefa 12:** strings() devolve {locale, messages} (o Intl do JS precisa do idioma) e a versão vem do comando plugin:app|version do Tauri; o e2e compara com CARGO_PKG_VERSION, que só vira 0.2.0 na Tarefa 17 — custo se errado: trocar a asserção.
- **Tarefa 12:** call usa os nomes snake_case do ServiceProxy e args é um objeto JSON com os nomes dos parâmetros; set_preferences recebe values=[[chave, valor]] — custo se errado: ajustar as telas.
- **Tarefa 12:** qualquer resposta do serviço (mesmo um erro dele) conta como "no ar"; Unavailable cobre nome sem dono, objeto desconhecido, NoReply e erro de E/S — custo se errado: aviso que não aparece num caso raro.
- **Tarefa 12:** UITheme aceita light e dark (a spec fala de "sistema ou claro"; dark sai de graça com light-dark()) — custo se errado: nenhum.
- **Tarefa 12:** Sobre mínimo nesta tarefa (versão, GPL-3.0, aviso não oficial, página do projeto); as outras telas mostram "em construção" até as Tarefas 13–16 — custo se errado: nenhum.
- **Tarefa 12:** instalei webkitgtk6.0 (WebKitWebDriver) por pkexec e o tauri-driver 2.1.0 pelo cargo, como o plano prevê; o ícone do app é desenho próprio (assets/.../apps) — custo se errado: nenhum.
- **Tarefa 13:** o Fluent passou para o JS (parseFtl); strings() entrega o ftl cru e os títulos window-* foram para o main.ftl — um parser só, e os testes JS conferem os textos reais — custo se errado: reescrever o parser no Rust de novo.
- **Tarefa 13:** headerFor recebe o locale — sem ele o inglês mostrava "há 5 minutos" — custo se errado: nenhum.
- **Tarefa 13:** janela principal com 900×640 (não 380×560) — a 0.2 tem menu lateral e tabela, não cabe no tamanho da bandeja — custo se errado: trocar dois números.
- **Tarefa 13:** pesquisa pelo open_screen(screen, arg), com ?arg= na abertura e o evento screen-arg com a janela já aberta — a tela de pesquisa (Tarefa 16) consome os dois — custo se errado: um canal a mais.
- **Tarefa 13:** comandos locais open_link (tabela fixa, nada de URL vinda da página) e pick_folder (portal FileChooser) — a interface nunca abre endereço arbitrário — custo se errado: nenhum.
- **Tarefa 13:** e2e lê texto por innerText (o texto do elemento do WebDriver some com reticências), Xvfb 1920×1080x24 e LANG pt_BR; opens_in_under_1500ms mede Open("home") com a instância já rodando até o cabeçalho e os cartões aparecerem; o teste de sair pausa e grava pela montagem para ter envio na fila — custo se errado: a meta medida a frio fica de fora.
- **Tarefa 13:** fora da 0.2, conforme a tabela do plano: Pastas conectadas, Drives compartilhados e Compartilhar — custo se errado: nenhum.

- **Tarefa 14:** o e2e desconecta a conta do serviço de teste (logout discard) e entra de novo pela tela, em vez de subir um segundo serviço sem conta — um serviço só no e2e.sh; o teste termina com a conta conectada, como os outros esperam — custo se errado: se o teste falhar no meio, os seguintes caem sem conta.

- **Tarefa 14:** o tempo esgotado é o LoginFinished com erro que o serviço manda após 5 min (LOGIN_TIMEOUT); a tela volta ao passo 1 com a mensagem e "Tentar de novo", sem relógio próprio — uma fonte só para o prazo — custo se errado: a mensagem vem do serviço só em pt-BR.
- **Tarefa 14:** o passo off-line explica o `gdrive-desktop-linux pin <caminho>` da CLI — a 0.2 não tem o menu do Dolphin — custo se errado: trocar o texto quando o menu chegar.
- **Tarefa 14:** comando local open_mount (o caminho vem do Status do serviço, nunca da página) — a página não abre caminho arbitrário — custo se errado: nenhum.
- **Tarefa 14:** "Pular" no passo de login fecha a janela, sem login — a bandeja continua com "Fazer login" — custo se errado: nenhum.
- **Tarefa 15:** as "Configurações avançadas" são a terceira aba ("Configurações") em vez de uma janela à parte — uma janela só e o mesmo rodapé de Salvar — custo se errado: mover a aba para um diálogo.

- **Tarefa 15:** o tema oferece "Do sistema" e "Claro" (spec §6.10); um "dark" escrito à mão continua valendo até o usuário mudar — custo se errado: acrescentar uma opção.
- **Tarefa 15:** a lista de terceiros sai do cargo metadata no build.rs (dependências não-dev dos pacotes do workspace, sem o gdl-fake-drive), e não do Cargo.lock, que não traz licenças; se o cargo metadata falhar, o build avisa e a lista sai vazia — custo se errado: um build de pacote sem a lista (ver na Tarefa 17).

- **Tarefa 16:** e2e exige openbox no Xvfb — sem gerenciador de janelas o Xvfb tira o foco ao acaso (medido: blur entre 0,15 e 2,8 s em janelas comuns) e a pesquisa fecha no blur; o produto ficou com o fechamento simples — custo se errado: e2e pulado (77) onde não houver openbox

- **Tarefa 17:** os ícones ficam em assets/icons (tema hicolor, Tarefa 10), não em packaging/icons como lista o plano — a bandeja já procura ali no desenvolvimento e o instalador copia para <prefixo>/share — custo se errado: mover a pasta.
